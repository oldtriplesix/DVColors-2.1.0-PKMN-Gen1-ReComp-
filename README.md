# DVColors-2.1.0-PKMN-Gen1-ReComp-
DVColors2.1.0, a mod for Pokemon Gen 1 Recomp. Changes color palette slightly, or wildly (based on your preference) based on a Pokemon's DVs (IVs in later games). Pokemon Stadium on N64 did something similar with palette swaps for nicknames, so I figured it'd add some fun variance to your playthrough.
